# DAIL sound sources

Selected sounds by Kenney, released under Creative Commons CC0. Original license
files are included alongside the unmodified OGG sources.

- https://kenney.nl/assets/sci-fi-sounds — engineCircular_000, spaceEngineLow_000,
  doorOpen_000, doorClose_000, lowFrequency_explosion_000
- https://kenney.nl/assets/impact-sounds — impactPlate_heavy_000
- https://kenney.nl/assets/interface-sounds — click_001, switch_002

Downloaded 2026-09-07. License: https://creativecommons.org/publicdomain/zero/1.0/

Run `python3 scripts/build-soundtrack.py` (requires ffmpeg) to reproduce the WAV
cues in public/sfx. The mix uses filtering, gentle pitch reduction, envelopes,
restrained stereo echoes and peak control. No music or film soundtrack is used.
The finale release starts at 4.2 seconds, after silence from 3.08 seconds.
